# Attrition Intelligence

A full-stack Employee Attrition Prediction application built around the validated `best_f1_model.joblib` ensemble. The application provides protected prediction, history, operating modes, model metrics, and artifact-backed insights.

Run locally with `pnpm install`, `pnpm dev`, and Python dependencies from `requirements-python.txt`. The production image uses the included Dockerfile to provide Node.js and Python for the child-process inference bridge.
